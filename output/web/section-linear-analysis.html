    Section 4.2 Evaluation of Linear Models

    This section is a continuation of the previous on linear regression. Having defined what a linear regression is, I want to do some analysis of the quality of a regression. What is a good fit and how do we know? In this section, I will define three measures of the strength of a linear regression.
    🔗

    Definition 4.2.1.

    The correlation of a linear model is a number \(r\text{,}\) with values between -1 and 1. A value of \(r=1\) indicates a perfect match with a line with positive slope. A value of \(r=-1\) indicates a perfect match with a line of negative slope. As the value of \(r\) gets closer to zero, it indicates a weaker and weaker match with the line. (In some contexts, this number is more specifically called the Pearson correlation coefficient.)
    🔗
    🔗
    The term here is a bit annoying. We used ‘correlation’ already to indicate a relationship, with positive correlation indicating that both variable grow goether and negative correlation indicating an inverse relationship. Now ‘correlation’ is also a technical measure with the same name. This is frustrating, but it is standard terminology.
    🔗
    Let me use some diagrams to visualize correlation. What follows is a sequence of figures. The caption of each gives the correlation value, and you can see how the data becomes more scattered and less aligned to the linear model as the correlation gets close to zero.
    🔗
    As a final note about correlation, this tool only measures how something fits. Figure 4.2.9 is one last correlation figure.
    🔗
    This scatter plot Figure 4.2.9 has low positive correlation, r=0.14. There is a very slight positive correlation. However, the correlation coefficiententirely misses the fact that there is another kind of relationship here. A better model for this data would be a function that rises and then falls. Such a function is not a linear model, so the correlation number doesn’t see it at all.
    🔗
    In statistics, linear regression is almost always the first thing to try. But some data has relationships which are not linear. It’s very valuable to remember that linear models are only one of many kind of models of relationship between data.
    🔗
    Now let me define the second measure of a linear model, which is very closely connected to correlation.
    🔗

    Definition 4.2.10.

    The square of the correlation is simply called the \(R^2\) measure. In some contexts, this is called the coefficient of determination. However, simply referring to it as \(R^2\) is so common that I’ll stick with that convention. The fact that we’ve changed from a lower case ‘r’ to an upper case ‘R’ is annoying, but again this is the conventional notation.
    🔗
    🔗
    By squaring the correlation, a couple things happen. First, the value of \(R^2\) is always positive, so it ignores the difference between positive and negative slopes. Close to 0 means that the data probably doesn’t fit a linear model well, and close to 1 means a good fit. In this way, \(R^2\) is a slightly more elegant measure of linearity, and it gets used more often because of this. Second, by squaring, the numbers get slightly smaller. (If you square a number less than 1, it gets closer to zero). Therefore, \(R^2\) is a bit of a finer measure: \(R^2 = 0.9\) is a stronger indication of a good linear fit than a correlation of the same value.
    🔗
    In the previous section, I also talked about multiple regression: making linear models with multiple explanatory variables. There are extension of \(R^2\) to multiple regression as well. The one which we will use in the classroom activities is called adjusted \(R^2\). You can assume that adjusted \(R^2\) means that we must be dealing with several explanatory variables.
    🔗
    Now let me get back to residuals, since these can also be used to evaluate the quality of a linear regression. Residuals were defined in the last section: they are the difference, for each data point, bewteen the actual data, \(y\text{,}\) and the prediction of the linear regression, \(\hat{y}\text{.}\) There is a residual for each data point: n in total, where n is the number of cases.
    🔗
    From the previous section, recall Figure 4.1.3. It has a linear model with equation \(\hat{y} = 41 + 0.59x\text{.}\) The residuals are the difference between the y coordinate of the data point and the line. However, residuals are a bit tricky to see in the original scatterplot.
    🔗
    Instead, I can just plot the residuals themselves. Figure 4.2.12 shows the same data set, but the \(y\) axis is now the residual compared to the linear regression. The \(y\) value of each data point is simpliy how far it was, in the original diagram, away from the line.
    🔗

    Definition 4.2.11.

    A scatterplot where the \(y\) axis is the residual of a linear regression, instead of the original \(y\) value of the data point, is called a residual plot.
    🔗
    🔗
    As a visualization tool, the residual plot is extremely useful to seeing how good the regression is, since all it shows is the error for each data point. The shape and patterns of the residual plot can give information.
    🔗
    In general, if there is no pattern to the residual plot (and the residuals are not too large), that is good evidence that the original regression was pretty good. For the data shown in Figure 4.2.12, from the previous section, there isn’t much of a pattern to the residual plot, so the linear regression is probably a decent model of the relationship between the variables.
    🔗
    Figure 4.2.13 is another scatter plot with a linear regression. This looks like a pretty good regression.
    🔗
    Then, Figure 4.2.14 is the matching residual plot.
    🔗
    This residual plot looks pretty good. The residuals are balanced above and below the line, they are relatively small residuals, and there is no obvious pattern. This is evidence of a good linear regression: a line that fits the data well.
    🔗
    Figure 4.2.15 is another scatter plot with Figure 4.2.16 as it residual plot.
    🔗
    This residual plot is a bit different. There seems to be a pattern to the residuals: starting below, then moving above, then moving below. In the original scatterplot, the variance of the data from the line was difficult to read, visually. Here, the residual plot makes that much easier to read. This is the strength of a residual plot: it zooms in on the relationship between the data and the line, and can clearly show things that were present in the original scatterplot but were much harder to see. In this case, the relationship is still close to linear, but this pattern means that there is probably something else going on here as well, something non-linear between the two variables.
    🔗
